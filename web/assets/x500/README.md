# x500 models

From [hakoniwa-threejs-drone](https://github.com/hakoniwalab/hakoniwa-threejs-drone) (MIT, Hakoniwa Lab) at
`562b719`, unchanged:

- `x500-frame.glb`: `assets/models/x500/x500-frame.glb`, the X500 MJCF of Hakoniwa Drone converted to Three.js axes
  (right, up, back).
- `base-drone-prop.glb`: `assets/models/base-drone-prop.glb`, a 0.296 m propeller; the Flight tab scales it by 0.858
  to the X500's 10-inch span, as `config/drone_types-x500.json` does.
